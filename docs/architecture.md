# Архитектура MVP

## Цель

Сервис поддерживает безопасный голосовой навык для напоминаний о лекарствах и справочной информации о препаратах без выхода в зону медицинских рекомендаций.

## Общая схема

```text
Пользователь (голос)
        ↓
Voice Layer / SmartApp API
        ↓
NLU / Intent Parser
        ↓
Dialog Handler
        ↓
Backend Services
        ↓
JSON Storage / База данных
        ↓
Mock Pharmacy API Adapter
```

## Компоненты

### 1. Voice Layer

- Получает голосовую фразу
- Передаёт текст или intent в backend
- Поддерживается через webhook SmartApp API: `POST /api/v1/sber/webhook`

### 2. NLU

- Определяет intent
- Извлекает параметры: название препарата, время, длительность курса, запрос по аптеке
- Поддерживает пошаговый диалог, если данных не хватает

### 3. Dialog Handler

- Управляет многошаговым сценарием `Добавь лекарство`
- Формирует короткие безопасные ответы
- Учитывает режим для пожилых пользователей

### 4. Medication Service

- Создаёт лекарства
- Хранит расписание
- Выдаёт статус курса
- Подтверждает факт приёма

### 5. Reminder Service

- Генерирует напоминания по расписанию
- Повторяет уведомление при отсутствии ответа
- Создаёт событие для родственника после нескольких пропусков

### 6. Drug Info Service

- Возвращает только справочную информацию
- Формулирует ответы через `По инструкции препарат используется для...`
- Всегда добавляет дисклеймер

### 7. Pharmacy Service

- Ищет аптеки по названию препарата
- Сортирует варианты по цене и расстоянию
- В MVP работает на mock-данных, но отделён адаптером и готов к замене на реальный API

## Безопасность и модерация

В систему встроены два слоя защиты.

### Medical Disclaimer

Во все справочные ответы о препаратах добавляется текст:

`Информация носит справочный характер и не заменяет консультацию врача.`

### Response Filter

Система блокирует или перенаправляет запросы, если пользователь пытается получить:

- диагноз
- назначение лечения
- персональную рекомендацию вида `что мне принимать`

Вместо этого ассистент отвечает, что может предоставить только справочную информацию и советует обратиться к врачу.

## Что покрывает MVP для защиты

- Добавление лекарства
- Напоминания
- Подтверждение приёма
- Учёт курса
- Безопасная справка о препарате
- Поиск аптек на mock-данных
